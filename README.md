# ドリームキャッチ ✨ (Dream Catch)

空から降ってくるキラキラの星やハート、キャンディを、まるっこくてかわいいうさぎちゃんでキャッチする、シンプルでかわいいブラウザアクションゲームです！

---

## 🌟 リニューアルのポイント

- ⏱️ **60秒の時間制限スコアアタック**: サクッと遊べる60秒の制限時間を追加！残り10秒を切るとドキドキのカウントダウン演出や秒針音が鳴ります。
- 🐰 **キビキビ動いて気持ちいい操作感**: 左右キーでてくてく移動し、キーを離すとピタッと止まります。スペースやJUMPボタンでぴょん！とジャンプでき、着地時にはぽよんと縮む自然で心地よいアニメーション！
- 🌸 **すっきりシンプル＆かわいい画面**: ごちゃごちゃした装飾を削ぎ落とし、淡いパステルピンクと空色のグラデーション、ぽわんとした白い雲、つぶらな瞳のモチモチうさぎちゃんを配置。
- 🎵 **やさしいトイピアノ＆オルゴール音**: 外部音源不要のWeb Audio APIで、耳に心地よいポロン音やジャンプ音、やさしいメロディを奏でます。
- 📱 **スマホ＆PC両対応**: パソコンのキーボード操作はもちろん、スマホの押しやすいフラットパステル丸ボタンで快適に楽しめます。

---

## 🎮 操作方法

### パソコン（PC）
- **移動**: `[←]` `[→]` キー または `[A]` `[D]` キー
- **ジャンプ**: `[スペース]` キー または `[↑]` / `[W]` キー

### スマートフォン
- 画面下の丸ボタン：
  - `[←]` `[→]`: てくてく左右移動
  - `[JUMP]`: ぴょんとジャンプ！

---

## 🚀 起動方法

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて遊べます。
